<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client form → Server Action/module | Forged identifiers / unverified-but-claimed-verified fields |
| draft state → domain tables | Half-verified data must not reach Customer/Vehicle |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-12 | Tampering | client marks a field "verified" without human check | mitigate | server-side assertVerified re-checks the verified map + re-runs pure validators (Pattern 3); save throws |
| T-03-13 | Tampering/Integrity | forged/invalid identifier bypasses client validation | mitigate | verify-gate re-runs isValid* validators server-side regardless of client flags (Pitfall 5) |
| T-03-14 | Repudiation | verified PII persisted without audit | mitigate | verifiedBy/verifiedAt + recordAudit(tx,…) for each entity inside the save transaction |
| T-03-15 | Tampering | partial persistence on gate failure | mitigate | gate runs BEFORE the transaction; all writes in one $transaction (atomic) |
</threat_model>
