| Boundary | Description |
|----------|-------------|
| repo input → Postgres | Raw PII (chassis/engine/national ID) crosses into encrypted storage |
| OCR output → OcrResult | Untrusted raw text persisted; must NOT be normalized |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-03 | Information Disclosure | Vehicle chassis/engine at rest | mitigate | CryptoService AES-256-GCM envelope; decrypt only in vehicle.repo; blind index via HMAC |
| T-03-04 | Repudiation | PII writes without audit | mitigate | recordAudit(tx,…) in the SAME db.$transaction as every write; audit failure fails the write |
| T-03-05 | Tampering/Integrity | OcrResult normalized/cleaned before storage | mitigate | ocr-result.repo persists rawPayload verbatim; int test asserts byte-equality (no trim/uppercase) |
| T-03-06 | Tampering | SQL injection | accept | Prisma parameterized queries only; no raw SQL in these repos |
</threat_model>
