| browser form → Server Action/route handler | Untrusted inputs + uploaded file |
| client validation → server | Client validation is UX only, never trusted |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-16 | DoS/Tampering | unrestricted file upload (oversize/wrong type) | mitigate | server-side size + MIME allowlist before OCR; store as opaque encrypted blob (03-03) |
| T-03-17 | Tampering | client-side-only identifier validation bypass | mitigate | server re-parses the same zod schema + verify-gate (03-04); client validation is UX |
| T-03-18 | Information Disclosure | crypto/repo imported into a client component | mitigate | actions/service are server-only; components call actions, never repos/crypto directly |
| T-03-19 | Information Disclosure | raw PII/OCR logged | accept→mitigate | do not log decrypted PII/raw OCR in actions; rely on audit-in-tx for access record |
</threat_model>
