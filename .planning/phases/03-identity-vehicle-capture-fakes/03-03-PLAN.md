## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| uploaded file → storage | Untrusted bytes/mime cross into encrypted blob storage |
| user-influenced ref → filesystem path | Potential path traversal |
| OCR raw text → mapper | Untrusted text; mapper must not validate identifiers |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-07 | Information Disclosure | uploaded documents at rest / web-served | mitigate | AES-256-GCM via CryptoService; write under ./.uploads (gitignored, outside public/); never static-served |
| T-03-08 | Tampering | path traversal via storage ref | mitigate | server-generated cuid refs; resolved path asserted inside UPLOAD_DIR; reject ../ + absolute (unit-tested) |
| T-03-09 | Tampering/Integrity | mapper/LLM validating identifiers | mitigate | MapperProvider has no validator dependency; structural source test asserts no validators import (CMI-04) |
| T-03-10 | Information Disclosure | crypto in client bundle | mitigate | registry.ts marked `import "server-only"` |
| T-03-11 | Tampering | OCR output cleaned before persistence | mitigate | OcrResultRaw Zod schema validates shape only; fake adapter returns fixture verbatim (CUST-04) |
</threat_model>
