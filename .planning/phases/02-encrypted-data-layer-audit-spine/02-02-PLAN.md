<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller → repo | Plaintext PII + ActorContext enter; only ciphertext/blind-index persist; cleartext returns only from readPii |
| repo → Postgres | Parameterized Prisma queries; encrypted columns + audit rows |
| DATABASE_URL → migrate/seed | Connection secret from env; never committed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-06 | Repudiation | PII read/write without an audit trail | mitigate | Audit row written in the SAME $transaction as the data op via explicit repo (not $extends); rollback test proves atomicity |
| T-02-07 | Information Disclosure | PII stored in plaintext | mitigate | CryptoService envelope on nationalId/passport/document/chassis; integration test asserts column is not cleartext |
| T-02-08 | Information Disclosure | Equality leakage via blind index | mitigate | HMAC-SHA256 with separate INDEX_KEY; @unique enforces dedupe without exposing plaintext |
| T-02-09 | Tampering | SQL injection | mitigate | Prisma parameterizes all queries; no raw string SQL |
| T-02-10 | Information Disclosure | Decimal→number float drift on money | mitigate | Convert Decimal→big.js Money at repo boundary; Decimal columns only (no Float/Double) |
| T-02-11 | Information Disclosure | Secrets in migration/seed files | mitigate | No literal keys/connection strings in migrations or seed.ts; env-only; gitleaks gate (Plan 03) |
| T-02-SC | Tampering | npm installs | mitigate | No new packages beyond Plan 01's fixed stack; nothing to verify |
</threat_model>
