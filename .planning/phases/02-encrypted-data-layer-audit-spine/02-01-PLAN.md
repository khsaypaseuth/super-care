<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| env → CryptoService | Key material crosses from VPS env into the process; must never be logged or committed |
| caller → CryptoService | Plaintext PII enters; ciphertext/blind-index leave; cleartext must not escape the owning module |
| repo → generated client | Generated Prisma client is a build artifact, never committed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | Master/index keys in source | mitigate | Keys only via EnvKeyProvider from env; no literal in any file; `.env*` gitignored; gitleaks gate (Plan 03) |
| T-02-02 | Tampering | Ciphertext at rest | mitigate | AES-256-GCM auth tag verified on decrypt (tamper → throw); unit test asserts flipped-tag throws |
| T-02-03 | Information Disclosure | Equal-plaintext ciphertext correlation | mitigate | Random 12-byte IV per encryption; unit test asserts two encryptions differ |
| T-02-04 | Information Disclosure | Blind-index brute force / cross-key leak | mitigate | HMAC-SHA256 with a SEPARATE secret INDEX_KEY (not plain hash, not the master key); test asserts index depends on indexKey |
| T-02-05 | Information Disclosure | Crypto/keys reaching the browser | mitigate | All crypto under `apps/web/src/server/**`; never imported into client components |
| T-02-SC | Tampering | npm installs (prisma, @prisma/client, tsx) | mitigate | All first-party/fixed-stack, registry-verified in 02-RESEARCH Package Legitimacy Audit; no [ASSUMED]/[SUS] packages → no blocking checkpoint needed |
</threat_model>
